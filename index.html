01 · Fintech & Payment Security
Payment Extension Security Fix Laravel Sanctum

Custom Shopify Payment Extension & Token Remediation

Connected a finance-sector merchant's proprietary payment platform directly to Shopify checkout — handling authorization, 3DS verification, and live status inside checkout instead of external redirects.

Vulnerability API tokens leaked in frontend JS bundles & browser requests.
Fix Applied Vaulted tokens server-side via Laravel Sanctum with encrypted session refs.
Outcome End-to-end 3DS checkout with HMAC-verified webhook callbacks.
payment-audit.diff
// Before: API token exposed in browser request
−fetch('/api/payment', { headers: { Authorization: window.__API_TOKEN__ } })
// After: server-side Sanctum vault + HMAC verified callbacks
+fetch('/api/payment/initiate', { body: JSON.stringify({ sessionRef: encryptedId }) })
+// ✓ Token isolated server-side + webhook HMAC verified
01 / Checkout submits only an encrypted session reference — zero API secrets reach the browser.
