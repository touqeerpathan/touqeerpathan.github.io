Case 01 · Fintech & Payment Security
Payment Extension Security Fix Laravel Sanctum

Custom Shopify Payment Extension for a Finance-Sector Merchant

Connected the merchant's proprietary payment platform directly to Shopify checkout via a custom Payment Extension — handling authorization, 3DS verification, and transaction status natively inside checkout instead of redirecting users off-site.

Risk Identified API tokens were exposed in frontend JS bundles & browser requests.
Engineering Fix Isolated tokens server-side via Laravel Sanctum with encrypted session refs.
Verified Result End-to-end 3DS checkout with HMAC-verified webhook callbacks.
payment-architecture.inspect
// Before: credential passed directly from browser
−fetch('/api/payment', { headers: { Authorization: window.__API_TOKEN__ } })
−// ⚠ Token visible in Network tab & frontend bundle
// After: server-side token vault + signed callback
+fetch('/api/payment/initiate', { body: JSON.stringify({ sessionRef: encryptedId }) })
+// ✓ Token stored & verified server-side via Laravel Sanctum
+// ✓ Webhook HMAC signature validated on every async callback
01 / Checkout initiates payment with an encrypted session reference only — zero API tokens ever touch the client.
