Selected Case Studies

Case 01 · Fintech & Security
Payment Extensions Laravel Sanctum 3DS Flow OWASP

Custom Shopify Payment Extension & Token Exposure Remediation

Connected a finance-sector merchant's proprietary payment platform directly to Shopify checkout via a custom Payment Extension — handling authorization, 3DS verification, and real-time transaction state inside checkout rather than redirecting off-site.

Vulnerability Found

API tokens were passed in frontend browser requests, exposing sensitive credentials in the network tab and JS bundle.

Architecture Fix

Moved all token exchange server-side using Laravel Sanctum with encrypted session references and strict request validation.

Production Outcome

End-to-end 3DS checkout payments with signed HMAC callback verification hardened prior to launch.

payment-extension-audit
// Before: credential leaked in client request & JS bundle
−fetch('/api/payment', { headers: { Authorization: window.__API_TOKEN__ } })
−// ⚠ Token exposed in browser DevTools & lacks callback verification
// After: token isolated server-side with signed webhooks
+fetch('/api/payment/initiate', { body: JSON.stringify({ sessionRef: encryptedId }) })
+// ✓ Token vaulted server-side via Laravel Sanctum + per-request verification
+// ✓ Webhook HMAC signature verified on every async status callback
01 / Shopify Checkout submits an encrypted session reference only — zero API secrets ever reach the browser or JS bundle.
